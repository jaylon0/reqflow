# migrate

迁移辅助。评估迁移范围，制定迁移计划，执行迁移。

## 触发条件

- 框架升级
- 库版本升级
- API 迁移
- 数据库迁移

## 方法论

### Step 1: 评估迁移范围

1. 旧版本 API
2. 新版本 API
3. 差异分析
4. 影响范围

### Step 2: 制定迁移计划

1. 分阶段迁移
2. 兼容性处理
3. 回滚方案
4. 测试策略

### Step 3: 执行迁移

1. 替换 API 调用
2. 更新配置
3. 运行测试
4. 修复问题

### Step 4: 验证

1. 功能验证
2. 性能验证
3. 兼容性验证

## 输出格式

```
## 迁移报告

### 迁移概述
[从什么迁移到什么]

### 影响范围
[涉及的文件和模块]

### 迁移计划
[分阶段计划]

### 执行结果
[迁移结果和问题]

### 验证结果
[测试结果]
```

## 注意事项

- 要有回滚方案
- 要分阶段迁移，不要一次性全改
- 要充分测试
- 要记录迁移过程
