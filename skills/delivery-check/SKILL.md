# delivery-check

交付验证。检查产物完整性、功能正确性、质量标准。

## 触发条件

- 功能开发完成
- 准备交付
- 验收前检查
- 质量检查

## 方法论

### Step 1: 检查产物完整性

1. 文件是否存在
2. 内容是否完整
3. 格式是否正确

### Step 2: 验证功能

1. 运行测试
2. 手动验证关键路径
3. 检查边界条件

### Step 3: 检查质量

1. 代码风格
2. 文档是否更新
3. 无遗留 TODO
4. 无已知 bug

### Step 4: 输出验收报告

1. 通过/不通过
2. 遗留问题
3. 改进建议

## 输出格式

```
## 交付验证报告

### 验证范围
[检查了哪些内容]

### 产物完整性
| 文件 | 状态 | 备注 |
|------|------|------|
| ... | ✅/❌ | ... |

### 功能验证
[测试结果]

### 质量检查
[代码风格、文档、TODO]

### 结论
[通过/不通过]
```

## 注意事项

- 要检查所有产物，不要遗漏
- 要运行测试，不要只看代码
- 要关注遗留问题
- 要给出明确结论
